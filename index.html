This turns a clinical algorithm into its own interactive case game — instead of flashcards, you manage one patient step by step: narrative reveals, vitals/exam/labs you tap to check, then a decision with real consequences (score, feedback, a teaching pearl) before the case moves on. It's a small structured format called CASE_FORMAT (v1.0, or v1.1 for optional randomized outcomes — see below) — most easily generated by pasting your algorithm into an LLM using the prompt below, rather than hand-written. A minimal valid case looks like this: CASE_FORMAT_VERSION: 1.0 CASE_TITLE: Example START_NODE: INTRO ---------------------------------------- NODE: INTRO TYPE: SCENE NARRATIVE: A patient presents with... NEXT: DECIDE ---------------------------------------- NODE: DECIDE TYPE: DECISION QUESTION: What do you do next? CHOICE: Order the right test -> END_GOOD EXPLAIN: Correct — because... CHOICE: Skip it -> END_BAD EXPLAIN: Not ideal — because... ---------------------------------------- NODE: END_GOOD TYPE: END END_TYPE: SUCCESS SUMMARY: Nicely managed. ---------------------------------------- NODE: END_BAD TYPE: END END_TYPE: FAIL SUMMARY: That path missed something important. ---------------------------------------- SCENE nodes reveal narrative and step forward via NEXT; DECISION nodes pose a QUESTION with 2+ CHOICE lines (each can carry its own SCORE / EXPLAIN / PEARL); END nodes close the case with END_TYPE and a SUMMARY. VITALS, EXAM, LABS, IMAGING, IMAGE, and HINT are optional fields on any SCENE, DECISION, or RANDOM node, revealed on tap rather than shown all at once. Want the same case to play out differently each time — a lab result that's sometimes positive, sometimes not? Use a RANDOM node instead of SCENE: it has 2+ OUTCOME blocks (each with its own optional WEIGHT, NEXT, and narrative/findings) and the engine randomly picks one, weighted, every time that node is reached: NODE: GET_ANA TYPE: RANDOM NARRATIVE: You send the ANA titer. OUTCOME: POS WEIGHT: 1 NARRATIVE: Result: ANA positive at 1:320. NEXT: WORKUP_POSITIVE OUTCOME: NEG WEIGHT: 1 NARRATIVE: Result: ANA negative. NEXT: WORKUP_NEGATIVE The pick is locked in for that playthrough, so revisiting or resuming shows the same result — restarting the case rerolls it. See the full spec in the LLM prompt below for details.
